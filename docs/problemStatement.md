Problem Statement: Warehouse teams and customers often lack a single real-time view of inbound/outbound truck movement, yard location, trailer availability, and dock-door assignments. This solution combines a customer-facing delivery tracker with an operations dashboard that uses WMS feeds to identify where a truck/trailer is located, estimate arrival time, and recommend the appropriate dock door based on availability and planned arrival. 

Data Source: Simulated WMS feed containing trailer ID, tracking number, current yard location, dock-door availability, appointment/arrival time, load priority, and ETA. Mapping APIs can be used for imulated live truck movement.

Objective and outcome: 1. Accept a tracking number, trailer ID, or shipment reference. 2. Display simulated real-time truck location on a map with updated ETA and delivery progress. 3. Receive WMS feed for yard location, trailer status, scheduled arrival, and dock-door availability. 4. Identify the trailer that needs to be docked for each arrival window. 5. Recommend or assign an available dock door based on arrival time, trailer/load type, priority, and dock availability. 6. Alert operations users when a truck is delayed, a dock is unavailable, or reassignment is needed. 7. Output: live map tracker, yard status board, dock-door assignment schedule, ETA alerts, and trailer-to-door allocation summary
